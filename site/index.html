Features

Built for devs who actually use their disk.

Smart Clean

Review caches, logs and build output by area, then clean the selected items.

Trash and Restore

Regenerable files are removed directly. Other items use the Trash. Enable Always use the Trash to use it for every cleanup.

Safety levels

Review each item before acting. Protected data and files used by running apps are held back.

Storage explorer

Explore folders in a treemap or list, find large files, and review selected items before moving them to the Trash.

App removal

Inspect an app and its related files together. Remove selected files, uninstall an app, or review leftovers.

History

See previous cleanup actions and restore items that are still in the Trash without replacing existing files.

Safety

Three signals,
one decision.

Every scanned path is graded so you can power through obvious wins and pause on the rest.

safe

Regenerable cache.

Smart Clean selects eligible caches and build output for review.

review

Project artifacts & large stores.

Review the rebuild cost and keep files that your work still needs.

hold

User data or live state.

Review valuable files separately. Items used by running apps are held back.
